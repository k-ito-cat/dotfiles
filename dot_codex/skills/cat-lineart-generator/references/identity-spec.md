# 固定個体仕様

## 個体と画風

すべての出力は同じ 1 匹の洗練された猫線画キャラクターの別ポーズである。品種や毛質は定義しない。毛並み・毛束・個々の毛は描かず、滑らかな輪郭だけで表す。

- 標準的でバランスの取れた体型。細身にもふっくらにも寄せず、胴体はやや細長く、厚みは一定に保つ。
- 頭は身体に対して控えめ、脚はほどよく細め、耳は自然な三角形。頭と肉球を過度に丸く・大きくしない。
- 目と鼻は描かない。口だけは最小限の短い線として許可し、ひげは描かない。写実的な顔や感情を強調する顔パーツは描かない。
- 黒のマーカーのような均一線。線幅はキャンバス短辺の約 0.7% とし、端と角は丸くする。筆圧による太さの変化、先細り、かすれ、カリグラフィー風の線は使わない。輪郭と最小限の内部線だけを使う。
- 塗り、陰影、グラデーション、ハッチング、テクスチャ、反復したラフ線は禁止。
- 大人向けのアートブックやエディトリアル線画のように、洗練・抑制・わずかな距離感を備える。伸びやかなプロポーション、抑制した非対称性、彫刻的なシルエット、十分な余白を優先し、解剖学的な厳密さや漫画的な表情に寄せすぎない。
- ポーズに応じた視覚的なバランス・身振り・優美さのためのスタイライズは許可する。ただし、親しみや遊び心を主目的にしたキャラクターデザイン、マスコット、ロゴ、丸く単純化したシルエット、ちびキャラ、子猫比率、誇張した頭や丸い肉球、過度に対称な正面アイコン、ソフトな漫画表現、児童書的なかわいさは禁止する。標準体型・頭身・四肢・尻尾の固定比率を崩す極端なデフォルメと、写実的な毛表現も禁止する。

## 線パターン

- `continuous-outline` — 既定。連続した滑らかな輪郭線で身体と尻尾を描く。従来の線画表現を変更しない。
- `separated-silhouette` — ユーザーが明示した場合のみ使用する。胴体・尻尾・独立して表現する四肢を、それぞれ開放輪郭として描く。形態同士の輪郭線は接続・重なり・交差させず、解剖学的な接続部には意図的で清潔な空隙を残す。線幅、丸端、線の滑らかさ、塗りなしの条件は `continuous-outline` と共通にする。

## 尻尾の不変条件

胴体長は首の付け根から尾の付け根までの中心線長、尻尾長は尾の付け根から先端までの中心線長として測る。曲がっていても直線距離にはしない。

```text
tail centerline length / torso centerline length = 1.00 ± 0.05
```

尻尾の向き・カーブ・上下・垂れ方はポーズに応じて変えてよい。長さと基本太さの比率は変えない。見かけの短縮を許容しても、解剖学的長さを短縮・伸長してはならない。

## 参照画像の登録

参照画像には役割とパスを記録して使用する。伸び・丸まりなど強いポーズの画像は `style_identity` にのみ登録する。中立立位・横向きで、体幹・四肢・尻尾全体が確認できる画像を得たら `neutral_proportion` として優先利用する。

`neutral_proportion` が未登録の間も、上の数値と固定個体仕様を守る。中立姿勢がないことを理由に、伸びポーズの脚や胴体長を新しいポーズへ転写しない。
